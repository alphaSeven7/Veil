许可与使用条款

本软件按「现状」提供，不附带任何明示或暗示的担保。使用者需自行承担使用风险。

Veil 是一款浏览器环境隔离与指纹管理工具，其设计用途包括：多账号运营环境隔离、跨浏览器兼容性测试、Web 反爬与风控系统的自查与对抗性测试、隐私保护研究、自动化测试基础设施等。

请勿用于违法用途。使用者不得将本软件用于违反目标网站服务条款的行为、欺诈、身份冒用、规避法律监管、干扰计算机信息系统等任何非法活动。因使用本软件产生的任何后果由使用者自行承担。

数据与隐私：Veil 不收集、不上传任何用户数据。全部窗口配置、浏览数据、代理凭据均保存在本机 ~/Library/Application Support/Veil/ 目录中。可选的主密码加密使用 AES-256-GCM，密钥由你的密码经 PBKDF2-HMAC-SHA256（120,000 次迭代）本地派生，不存储密码本身。

本地网络端口：Veil 会监听 127.0.0.1 上的两个端口 —— 一个用于本地 API（默认 54345），一个用于向自检页提供资源；启动的每个浏览器实例还会各自监听一个 127.0.0.1 上的 Chrome DevTools Protocol 端口。这些端口都只绑定回环地址，不对外网暴露。但请注意：本机上具有你同等权限的其它进程也能连接这些端口，这是 CDP 注入方案的固有特性。

第三方组件：Veil 不包含 Chromium 源码，它启动并控制你系统上已安装的 Chrome / Chromium / Edge / Brave。这些浏览器各自遵循其原始许可协议。

技术边界：TLS/JA3、HTTP/2 指纹由真实浏览器二进制决定，无法通过注入改写。Veil 会默认让伪造的 UA 版本贴近本机 Chrome 版本以降低矛盾，但这不等于完全不可识别。请在决策前充分理解这一限制。
