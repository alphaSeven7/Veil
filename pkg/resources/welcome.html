Veil 指纹浏览器

macOS 原生反检测浏览器控制台 · 将安装到「应用程序」文件夹
Veil 能做什么
  • 多窗口完全隔离 —— 每个窗口独立的 --user-data-dir，Cookie / LocalStorage / IndexedDB / 缓存 / Service Worker 互不相通。
  • 30+ 项指纹伪造 —— Canvas、WebGL、AudioContext、字体、屏幕、时区、语言、WebRTC、硬件参数、媒体设备、电池、存储配额、Client Hints 等，全部由「指纹种子」可复现地生成。
  • 代理自动认证 —— 内置本地中继，为带账号密码的 HTTP / HTTPS / SOCKS5 代理自动完成认证（Chrome 的 --proxy-server 本身不支持凭据）。
  • 本地 API —— 接口协议兼容比特浏览器（默认 127.0.0.1:54345），可直接对接 Selenium / Playwright / Puppeteer / RPA。
  • 指纹自检 —— 内置探针页，在目标窗口内实测并逐项比对配置期望值。
关于安全提示：本应用为自签名（ad-hoc）构建，未经 Apple 公证。安装后首次打开若被 Gatekeeper 拦截，请在「访达 → 应用程序」中右键点击 Veil → 打开，或在「系统设置 → 隐私与安全性」中允许。安装脚本会自动清除隔离属性。
